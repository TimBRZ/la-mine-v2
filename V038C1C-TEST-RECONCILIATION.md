## Télégraphes protégés

La classification repose sur la fonction de l'attaque, pas sur le mot « vapeur », « cône » ou « radial ». Un cône de **projectiles mobiles** du Souffleur peut partir immédiatement ; une zone conique dangereuse au sol conserve son avertissement. Même distinction pour les projectiles vapeur du Compresseur et les jets/zones vapeur persistants.

## Traitement des tests historiques

Les tests qui comparent un replay temporel entier au code d'avant le tir immédiat ne peuvent plus exiger l'identité du Run courant : positions, contacts et décisions divergent légitimement. Ils sont explicitement renommés comme **contrats historiques pré-instant** et exécutés avec les factories historiques cohérentes. Ils ne prétendent plus valider le combat actuel. Les comparaisons actuelles avec/sans ticks de rendu (V035B/V036C), les 51 contrôles C1b, les 107 nouveaux contrôles C1c et les autres tests actifs couvrent le code courant séparément.

Les verrous d'octets utilisent `instant-fire-compat.js` : avant de lire une source historique, les octets courants doivent correspondre à l'empreinte C1b immuable, après inversion **exacte** des seuls changements C1c listés dans `reconciliation-source-delta.js`. Aucun renouvellement général des empreintes. Une modification supplémentaire échoue au contrôle. Les références originales et les copies des tests avant modification sont conservées dans `before-tests`.

Les rapports JSON produits par les simulations (`v027-run-*`, `v028-run.json`, `zone5-run-*`, métriques Zone 5) sont des sorties, pas des sources immuables. Leurs simulations continuent à vérifier victoire, caps, récompenses, vagues et autres garanties ; seuls leurs hashes historiques impropres à ces sorties ne sont plus exigés par le verrou V034B.

La revue automatique a refusé une commande qui aurait renouvelé les empreintes de référence. Cette commande n'a pas été exécutée. La solution retenue conserve ces empreintes et contrôle le delta exact ; rien ne reste bloqué par ce refus.
